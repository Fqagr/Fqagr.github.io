学习笔记：怎么搭一个自己的网站

GitHub Pages 是什么

GitHub Pages 是 GitHub 提供的免费静态网站托管服务。把网页文件放进一个仓库，它就能自动变成一个可以访问的网站。

基本步骤

  1. 注册 GitHub，新建一个叫 用户名.github.io 的仓库。
  2. 把网站文件（HTML/CSS 或博客框架生成的文件）推送上去。
  3. 等一两分钟，访问 用户名.github.io 就能看到网站。

写新文章

每次想写东西，只要在本地新建一个 HTML 或 Markdown 文件，再推送上去就行了。
