21. 取整与 int

输出什么？

print(int(-3.5))

参考答案

1. print 输出

答案：C. None

f(n) 只执行 n += 1，没有 return，所以返回 None。

注：def 定义的函数如果不写 return，默认返回 None，并不会报错。

2. 字符串长度

答案：B. 5

"hello" 有 5 个字符。

注：对 str 做 len() 是可以的，因为字符串是可遍历的 iterable。

3. 集合长度

答案：B. 3

集合会去重，{1, 2, 2, 3} 实际是 {1, 2, 3}。

注：注意区分 dict 和 set。两者都用 {} 书写，set 中没有键值对，并且会自动去重。

4. 浮点数格式化

答案：A. 2.72

.2f 表示保留两位小数。

5. zip 配对

答案：A. [(1, 'a'), (2, 'b'), (3, 'c')]

zip 按位置配对，字符按原字符保留，不会转成整数。zip 中的每一项都是 tuple，不是 list。

6. 集合交集

答案：B. 2

交集是 {2, 3}。

注：set.union()、set.intersection()、set.difference() 分别对应并集、交集、差集，都会返回新集合。

7. 字符串替换

答案：A. "heLLo"

replace("l", "L") 会替换所有 "l"。

8. 字符串大小写

答案：A. "ABC"

upper() 转成全大写。

9. 字符串切分

答案：A. ['1', '2', '3']

split() 返回字符串列表，元素仍是 str。

注：记得仍是 str 类型

常用字符串方法：

名称 含义
len(s) 字符个数
s.find(sub) 查找子串，找不到返回 -1
s.index(sub) 查找子串，找不到抛出 ValueError

s.startswith(prefix) 是否以指定前缀开头
s.endswith(suffix) 是否以指定后缀结尾
s.upper() 转全大写
s.lower() 转全小写

s.replace(old, new) 替换子串

sep.join(iterable) 用分隔符拼接字符串元素

s.lstrip() 去左端空白

10. 字典更新

答案：B. 插入或覆盖键 "b"

如果 "b" 不存在就插入；如果存在就覆盖旧值。

11. 负数整除与取余

答案：B. -4 1

Python 的 // 是向下取整，所以 -7 // 2 是 -4。余数保持和除数同号，所以 -7 % 2 是 1。

12. 幂运算优先级

答案：B. 512

幂运算从右往左计算：2 ** 3 ** 2 = 2 ** 9 = 512。

13. or 短路求值

答案：C. 'x'

or 返回第一个真值。0 和 [] 都是假值，'x' 是真值。

and / or 不返回 True 或 False：

  • and 返回第一个为假的值；如果都为真，返回最后一个值。
  • or 返回第一个为真的值；如果都为假，返回最后一个值。

14. 字符串转整数

答案：D. 抛出 ValueError

int() 不能直接把 "3.5" 转成整数。应先 float("3.5")，或者使用 int(float("3.5"))。

15. 可哈希对象

答案：D. (1, 2)

字典键必须可哈希。列表、集合、包含列表的元组都不可哈希；纯数字元组 (1, 2) 可哈希。

注：即使 (1, [2]) 也不行。tuple 本身可哈希的前提是其中的所有元素也都可哈希。

16. 闭区间二分

答案：B. left <= right

闭区间 [left, right] 中，left == right 时还有一个元素需要检查，所以循环条件要允许相等。

17. 别名、浅拷贝与返回值

输出：

[[1, 3], [2]]
[[1, 3], [9]]
None
[[2], [1, 3]]

解释：

  • b = a[:] 是浅拷贝：外层列表是新列表，但内层 [1]、[2] 仍共享。
  • b[0].append(3) 修改的是共享的内层列表，所以会影响 a[0]。
  • b[1] = [9] 只是让 b[1] 指向新列表，不影响 a[1]。
  • list.reverse() 原地反转 a，但返回值是 None。

注：浅拷贝后，修改共享的可变内层对象(list,dict,set是共享的)会影响原列表；给外层元素重新赋值只改变当前列表中的引用，不影响另一个列表。
注：每次看到这都去拿 pythontutor 看一遍

18. 字典方法

输出：

0 False
4
[('b', 2), ('a', 1), ('c', 4)]

解释：

  • d.get('c', 0) 不会插入 'c'，所以 'c' in d 是 False。
  • setdefault('c', 4) 会插入缺失键并返回 4。
  • 字典保留插入顺序。

    注：setdefault 后一定要记得插入！！！

19. 递进与回归

输出：

3 2 1 1 2 3

解释：

  • 进入递归时依次打印 3 2 1。
  • 回到上一层后依次打印 1 2 3。
  • 最后一行 print() 只是换行。

注：使用 print() 时要注意 sep 和 end 参数。

20. deque 与短路

输出：

5 3
[2, 4, 1]
True

解释：

  • extendleft([4, 5]) 会把可迭代对象反着放到左端，得到 deque([5, 4, 1, 2, 3])。
  • 所以 popleft() 得到 5，pop() 得到 3。
  • 剩下 [4, 1, 2]，rotate(1) 右移一位，得到 [2, 4, 1]。
  • st 是空列表，not st 已经是 True，短路后不再判断 st[-1] == '('。

注：pop() 和 popleft() 都会弹出并删除对应端点的元素。
一定要弹出删除后再往下看！！！

21. 取整与 int

输出：

-3

解释：

int() 对浮点数做向零取整，不是四舍五入，也不是向下取整。int(-3.5) 得到 -3；如果想得到 -4，要用 math.floor(-3.5)。
