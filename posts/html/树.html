1. 常见递归统计

计算一般树高度

def height(node):
    if not node.children:
        return 0
    return 1 + max(height(child) for child in node.children)

计算二叉树节点总数

def count_nodes(node):
    if not node:
        return 0
    return 1 + count_nodes(node.left) + count_nodes(node.right)

计算二叉树叶子数

def count_leaves(node):
    if not node:
        return 0
    if not node.left and not node.right:
        return 1
    return count_leaves(node.left) + count_leaves(node.right)

错误写法是先访问 node.left，再判断空树。空树传入时会发生：

None.left

直接报 AttributeError。

2. 深度优先遍历 DFS 递归版

前序遍历

def preorder(node):
    if not node:
        return
    print(node.val, end=' ')
    preorder(node.left)
    preorder(node.right)

中序遍历

def inorder(node):
    if not node:
        return
    inorder(node.left)
    print(node.val, end=' ')
    inorder(node.right)

后序遍历

def postorder(node):
    if not node:
        return
    postorder(node.left)
    postorder(node.right)
    print(node.val, end=' ')

3. 遍历背后的栈和队列

前序、中序、后序都是 DFS，递归版本使用 Python 的调用栈。

也可以用显式栈模拟。

比如前序：

def preorder_stack(root):
    if not root:
        return

    stack = [root]

    while stack:
        node = stack.pop()
        print(node.val, end=' ')

        if node.right:
            stack.append(node.right)
        if node.left:
            stack.append(node.left)

注意先压右、再压左，这样弹出时才是先左后右。

中序显式栈写法：

def inorder_stack(root):
    stack = []
    node = root

    while stack or node:
        while node:
            stack.append(node)
            node = node.left

        node = stack.pop()
        print(node.val, end=' ')
        node = node.right

后序显式栈常用双栈：

def postorder_stack(root):
    if not root:
        return

    s1 = [root]
    s2 = []

    while s1:
        node = s1.pop()
        s2.append(node)

        if node.left:
            s1.append(node.left)
        if node.right:
            s1.append(node.right)

    while s2:
        print(s2.pop().val, end=' ')

4. 层序遍历 BFS

层序遍历是 BFS，按层从左到右访问，用队列。

from collections import deque

def level_order(root):
    if not root:
        return

    q = deque([root])

    while q:
        node = q.popleft()
        print(node.val, end=' ')

        if node.left:
            q.append(node.left)
        if node.right:
            q.append(node.right)

5. 表达式树 AST

表达式也可以画成二叉树。

例如 (3 + 4) * 2：

      *
     / \
    +   2
   / \
  3   4

三种遍历对应：

遍历 表达式形式 结果
前序 前缀表达式 * + 3 4 2
中序 中缀表达式 3 + 4 * 2
后序 后缀表达式 3 4 + 2 *

中序遍历表达式树时，如果去掉括号，运算优先级可能不明确，所以中缀表达式需要括号才严谨。

6. 二叉搜索树 BST

BST 是 Binary Search Tree，二叉搜索树。

性质：

对任意节点：左子树所有值 < 当前节点 < 右子树所有值，并且左右子树也分别满足 BST 性质。

注意是“整棵左子树”和“整棵右子树”，不是只比较直接左右孩子。

例如：

      50
     /  \
   30    70
  / \    / \
20  40  60  80

这是合法 BST。

7. BST 查找

def search(root, val):
    if not root:
        return False

    if root.val == val:
        return True

    if val < root.val:
        return search(root.left, val)
    else:
        return search(root.right, val)

查找 60 的路径：

50 -> 70 -> 60

每次比较排除一半，平均复杂度是：

O(log n)

8. BST 插入

def insert(root, value):
    if not root:
        return TreeNode(value)

    if value < root.value:
        root.left = insert(root.left, value)
    elif value > root.value:
        root.right = insert(root.right, value)

    return root

插入的本质：

  1. 按查找规则往下走。
  2. 找到空位 None。
  3. 创建新节点。
  4. 把新节点接回父节点。

为什么必须写：

root.left = insert(root.left, value)

因为 root.left 可能原来是 None，insert() 返回新建节点后要把它接回父节点。

同样，构建整棵树时要写：

root = insert(root, value)

不能只写：

insert(root, value)

否则第一次插入的新根会丢失。

一定要有东西来接收返回值！！！

9. BST 删除（待讲待查）

删除分三种情况。

情况 特征 操作
叶子节点 左右都为空 直接删除
只有一个孩子 只有左孩子或只有右孩子 用孩子替代自己
有两个孩子 左右都有 用后继节点替换，再删除后继

后继节点

后继是右子树中的最小值。

def find_successor(node):
    succ = node.right
    while succ.left:
        succ = succ.left
    return succ

删除代码：

def delete(root, val):
    if not root:
        return None

    if val < root.val:
        root.left = delete(root.left, val)
    elif val > root.val:
        root.right = delete(root.right, val)
    else:
        if not root.left:
            return root.right
        if not root.right:
            return root.left

        succ = root.right
        while succ.left:
            succ = succ.left

        root.val = succ.val
        root.right = delete(root.right, succ.val)

    return root

例如删除：

      50
     /  \
   30    70
  / \    / \
20  40  60  80

删除 50：

  1. 50 有两个孩子。
  2. 右子树是 70, 60, 80。
  3. 右子树最小值是 60。
  4. 用 60 替换 50。
  5. 再删除右子树中的 60。

错误做法是直接用左孩子或右孩子替代，这样可能破坏 BST 性质。
