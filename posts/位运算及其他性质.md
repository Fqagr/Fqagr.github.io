# 位运算与计算机数字存储

## 1. 位、字节和进制

计算机底层只有高低电平，逻辑上表示成 `0` 和 `1`。

- 1 位：`bit`
- 1 字节：`byte = 8 bit`

例如一个字节：

```text
0000 1010
```

表示：

```text
8 + 2 = 10
```

Python 里的进制前缀：

```python
0b1010   # 二进制，等于 10
0o17     # 八进制，等于 15
0xFF     # 十六进制，等于 255
10       # 十进制
```

十六进制每一位对应 4 个二进制位：

```text
F = 1111
F = 1111
FF = 1111 1111
```

所以 `0xFF` 是 8 个 `1`。

---

## 2. 字节怎么存储数字

一个 8 位无符号整数可以表示：

```text
0 ~ 255
```

因为 8 个位能组合出：

```text
2 ** 8 = 256
```

如果是有符号 8 位整数，通常用补码表示：

```text
-128 ~ 127
```

同一个二进制串可以按不同方式解释：

```text
1111 1111
```

- 解释成无符号整数：`255`
- 解释成有符号补码整数：`-1`

所以“数字是什么”取决于类型和解释方式。

---

## 3. 整数存储

### 3.1 无符号整数

无符号整数直接按二进制位解释：

```text
0000 0101 = 5
1111 1111 = 255
```

8 位范围：

```text
0 ~ 255
```

16 位范围：

```text
0 ~ 65535
```

### 3.2 有符号整数与补码

计算机通常用补码表示负数。

以 8 位为例：

```text
5  = 0000 0101
-5 = 1111 1011
```

求负数补码的规则：

```text
取反，然后加 1
```

例如 `5`：

```text
0000 0101
```

取反：

```text
1111 1010
```

加 `1`：

```text
1111 1011
```

这就是 `-5`。

### 3.3 为什么用补码

补码有几个好处：

1. 加法器可以同时处理正数和负数，不需要单独设计减法电路。
2. `0` 的表示唯一。
3. 加法自然回绕。
4. 符号位可以直接参与运算。

例如 8 位补码：

```text
0000 0101    5
1111 1011   -5
---------
0000 0000    0
```

最高位的进位被丢弃，所以结果正好是 `0`。

8 位补码范围是：

```text
1000 0000 = -128
0111 1111 = 127
```

---

## 4. 取反和补码的区别

按位取反是操作，补码是编码方式。

### 4.1 按位取反

按位取反是 `~`：

```text
0 -> 1
1 -> 0
```

例如：

```text
5  = 0000 0101
~5 = 1111 1010
```

这个 `1111 1010` 如果按 8 位补码解释，就是 `-6`。

### 4.2 补码

补码不是单纯取反，而是：

```text
取反 + 1
```

所以：

```text
~5 是取反操作
-5 是补码表示
```

在补码体系里有一个重要性质：

`:codex-annotation{index="1" id="6c9ce32c-b115-460f-80fe-8bbf571de74e"}`

```python
~x == -x - 1
```

为什么？

因为在补码体系里，全部位都是 `1` 表示 `-1`：

```text
8 位全 1：1111 1111 = -1
```

而：

```text
x + ~x = 全 1 = -1
```

移项得到：

```text
~x = -1 - x
```

也就是：

```python
~x == -x - 1
```

所以：

```python
~5 == -6
~0 == -1
```

## 5. 浮点数怎么存储

浮点数通常按 IEEE 754 存储，基本思想类似科学计数法：

```text
(-1)^sign * 1.mantissa * 2^exponent
```

32 位 float 一般分成：

```text
1 位符号
8 位指数
23 位尾数
```

64 位 double 一般分成：

```text
1 位符号
11 位指数
52 位尾数
```

例如十进制：

```text
0.5
```

二进制可以精确表示：

```text
0.1 二进制 = 1/2
```

所以：

```python
0.5
```

可以精确存储。

但：

```text
0.1
```

在二进制里是无限循环小数：

```text
0.0001100110011...
```

浮点数只有有限位，所以只能近似存储。

因此会出现：

```python
0.1 + 0.2
```

结果不是精确的 `0.3`，而是接近 `0.30000000000000004`。

这也是浮点数比较时不推荐直接用 `==` 的原因：

```python
abs(a - b) < 1e-9
```

## 6. 字节序

一个多字节数据在内存里的排列顺序叫字节序。

例如 32 位整数：

```text
0x12345678
```

按逻辑拆成 4 个字节：

```text
12 34 56 78
```

大端序：

```text
12 34 56 78
```

小端序：

```text
78 56 34 12
```

不同 CPU、文件格式、网络协议可能使用不同字节序，所以跨平台读写二进制数据时要注意。

---

## 7. Python 的 bytes

`bytes` 是字节序列。

```python
b = b"A"
print(b)          # b'A'
print(b[0])       # 65
print(len(b))     # 1
```

字符串编码成字节：

```python
"A".encode("utf-8")     # b'A'
"中".encode("utf-8")    # 多个字节
```

字节解码成字符串：

```python
b"A".decode("utf-8")    # "A"
```

`bytes` 和普通整数数组的关系很密切：

```python
list(b"A")             # [65]
bytes([65])            # b'A'
```

## 8. 位运算基础

常见位运算：

| 运算 | 符号 | 规则 |
|---|---|---|
| 与 | `&` | 两个都是 `1`，结果是 `1` |
| 或 | `|` | 只要有一个 `1`，结果是 `1` |
| 异或 | `^` | 两个不同，结果是 `1` |
| 取反 | `~` | `0` 变 `1`，`1` 变 `0` |
| 左移 | `<<` | 位整体左移，低位补 `0` |
| 右移 | `>>` | 位整体右移 |

例如：

```text
0101
&1100
----
0100
```

也就是：

```python
5 & 12 == 4
```

---

## 9. 与运算 `&`

与运算常用于“保留某些位”。

```python
x & 1
```

判断奇偶：

- 结果 `1`：奇数。
- 结果 `0`：偶数。

因为最低位决定奇偶。

取最低 8 位：

```python
x & 0xFF
```

例如：

```python
x = 0b10101101
print(x & 0b00001111)   # 13
```

结果只保留了低 4 位：

```text
1101
```

清零某一位：

```python
x & ~(1 << k)
```

---

## 10. 或运算 `|`

或运算常用于“设置某些位”。

把第 `k` 位设成 `1`：

```python
x | (1 << k)
```

例如：

```python
x = 0b1000
x = x | 0b0010
```

结果：

```text
1010
```

---

## 11. 异或运算 `^`

异或规则：

```text
相同为 0
不同为 1
```

重要性质：

```text
a ^ 0 == a
a ^ a == 0
```

`:codex-annotation{index="2" id="83565a0c-33b5-4cfa-9c12-ff960bdfb0e8"}`

```text
a ^ b ^ a == b
```

为什么？

因为异或满足交换律和结合律：

```text
a ^ b ^ a
= a ^ a ^ b
= 0 ^ b
= b
```

所以同一个数异或两次会抵消。

这也是“只出现一次的数字”这类题的经典解法：

```python
result = 0
for x in nums:
    result ^= x
```

所有出现两次的数都抵消，最后剩下只出现一次的数。

异或还能翻转某一位：

```python
x ^ (1 << k)
```

---

## 12. 取反 `~`

按位取反：

```text
0 -> 1
1 -> 0
```

Python 中：

```python
~5 == -6
~0 == -1
```

关系是：

```python
~x == -x - 1
```

清零第 `k` 位时常用：

```python
x & ~(1 << k)
```

因为 `~(1 << k)` 的意思是“除了第 `k` 位全是 `1`”，所以与运算后只清掉第 `k` 位。

---

## 13. 左移 `<<`

对非负整数，左移相当于乘以 2 的幂：

```text
10 << 1 = 20
10 << 2 = 40
```

公式：

```python
x << n == x * 2 ** n
```

例如：

```text
0000 1010 << 1
= 0001 0100
```

左移常用在构造掩码：

```python
1 << 0   # 0001
1 << 1   # 0010
1 << 2   # 0100
```

这可以表示不同的状态位。

---

## 14. 右移 `>>`

对非负整数，右移相当于整除 2 的幂：

```python
x >> n == x // 2 ** n
```

例如：

```text
10 >> 1 == 5
```

对负数要小心。

Python 里负数右移等价于向下取整：

```python
-1 >> 1 == -1
-7 >> 1 == -4
```

在 C/C++ 里，有符号数的右移行为通常由实现决定；无符号数右移是逻辑右移，高位补 `0`。

---

## 15. 掩码

掩码就是一段用于筛选二进制位的数。

判断第 `k` 位是否为 `1`：

```python
x >> k & 1
```

把第 `k` 位设成 `1`：

```python
x | (1 << k)
```

把第 `k` 位设成 `0`：

```python
x & ~(1 << k)
```

把第 `k` 位取反：

```python
x ^ (1 << k)
```

取出最低位的 `1`：

```python
x & -x
```

例如：

```text
12 = 1100
12 & -12 = 0100
```

判断是否是 2 的幂：

```python
x > 0 and x & (x - 1) == 0
```

例如：

```text
8 = 1000
7 = 0111
8 & 7 = 0000
```

## 16. 位运算表示状态

一个整数可以压缩多个布尔状态。

```python
1 << 0   # 状态 A
1 << 1   # 状态 B
1 << 2   # 状态 C
```

设置状态 A 和 C：

```python
status = (1 << 0) | (1 << 2)
```

判断是否有状态 A：

```python
status & (1 << 0)
```

添加状态 B：

```python
status |= 1 << 1
```

删除状态 A：

```python
status &= ~(1 << 0)
```

这种写法常用于权限系统、状态压缩 DP、图搜索状态等。

---

## 17. 位运算注意事项

Python 的整数不是固定 8 位或 32 位，而是任意精度整数。它不会像 C/C++ 那样简单溢出，但位运算语义仍然按补码规则模拟。

浮点数不能直接做常规位运算：

```python
1.5 & 1
```

会报 `TypeError`。如果需要看浮点数的底层二进制位，要用结构化转换，例如 Python 的 `struct` 模块。

跨语言或跨平台时要注意：

- 位宽是多少。
- 有符号还是无符号。
- 算术右移还是逻辑右移。
- 字节序是大端还是小端。
- 溢出后是回绕、截断还是报错。

---

## 18. 速记总结

- `bit` 是位，`byte` 是 8 个位。
- 无符号整数直接按二进制解释。
- 有符号整数常用补码表示。
- 补码求负数：取反加 1。
- `~x == -x - 1`。
- `&` 保留位、清位。
- `|` 设置位。
- `^` 翻转位、抵消重复值。
- `<<` 非负数乘 2 的幂。
- `>>` 非负数整除 2 的幂。
- `0b` 是二进制，`0o` 是八进制，`0x` 是十六进制。
- 浮点数用 IEEE 754 存储，很多十进制小数只能近似表示。
